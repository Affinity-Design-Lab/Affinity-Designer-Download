## 🧠 Overview

**Affinity Designer** is a powerful graphic design application for creating vector illustrations, branding, UI layouts, and print-ready artwork. It combines precision drawing tools with raster editing in a single workspace.

Built for Windows users, the software delivers smooth performance, supports professional file formats, and provides flexible tools for both beginners and experienced designers.
